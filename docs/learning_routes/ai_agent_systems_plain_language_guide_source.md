# AI Agent 系统实战路线通俗说明书

路线名称：AI Agent 系统实战路线：OpenCode / DeepReason / RAG / MCP
总时长：80 小时；节点数：26；阶段数：3

## 一句话说明
这条路线不是教你“从零发明一个 Agent 框架”，而是教你看懂并使用成熟 Agent 工具，把 OpenCode、Skill、MCP、RAG、证据链、记忆和评估组合起来，最终做出一个证据优先的研究型 Agent。

## 三阶段总览
- 基础阶段：概念与工具打底，5 节，11 小时。
- 强化阶段：核心工程能力强化，12 节，39 小时。
- 冲刺阶段：端到端项目冲刺，9 节，30 小时。

## 每节通俗说明
### 1.1 AI Agent 与 Chatbot 的区别
- 阶段：基础阶段
- 时长：2 小时
- 难度：偏易
- 前置：无
- 通俗解释：先把 Agent 和普通聊天机器人分清楚：聊天机器人主要负责回答，Agent 还会规划、调用工具、记录状态并反复修正。
- 学完标准：能用自己的话讲出“模型、工具、状态、循环”四个关键词。

### 1.2 LLM/API 基础知识
- 阶段：基础阶段
- 时长：3 小时
- 难度：中等
- 前置：无
- 通俗解释：补齐 LLM 和 API 的底层常识，知道一次模型调用从输入、上下文、参数到输出大概发生了什么。
- 学完标准：能独立完成一次 API 调用，并解释温度、上下文、token、结构化输出这些概念。

### 1.3 Agent 核心组件概述
- 阶段：基础阶段
- 时长：3 小时
- 难度：中等
- 前置：1.2
- 通俗解释：把 Agent 系统拆成零件看：模型负责思考，工具负责行动，权限负责边界，状态和会话负责连续性。
- 学完标准：能画出一个简单 Agent 的工作流程图。

### 1.4 OpenCode 仓库概览
- 阶段：基础阶段
- 时长：2 小时
- 难度：偏易
- 前置：无
- 通俗解释：先逛一遍 OpenCode 仓库，知道配置、命令、技能、Agent 定义这些东西分别放在哪里。
- 学完标准：能说清楚 OpenCode 项目里哪些文件决定 Agent 行为。

### 1.5 YAML 快速入门
- 阶段：基础阶段
- 时长：1 小时
- 难度：入门
- 前置：无
- 通俗解释：快速掌握 YAML 这种配置格式，因为很多 Agent 配置都用它或类似格式表达。
- 学完标准：能读懂并修改一个简单配置文件。

### 2.1 OpenCode 配置深度解析
- 阶段：强化阶段
- 时长：4 小时
- 难度：中等
- 前置：1.4、1.5
- 通俗解释：深入理解 OpenCode 的配置体系：哪些是全局配置，哪些是项目配置，哪些会影响工具权限和 Agent 行为。
- 学完标准：能安全地改一份 opencode/项目配置，并解释每个关键字段的作用。

### 2.2 创建自定义 Agent 与 Skill
- 阶段：强化阶段
- 时长：4 小时
- 难度：偏难
- 前置：2.1
- 通俗解释：动手创建自己的 Agent 和 Skill，把“会说话的模型”包装成“能承担特定任务的助手”。
- 学完标准：能做出一个专门负责某类任务的 Agent，以及一个可复用 Skill。

### 2.3 Sessions 与状态管理
- 阶段：强化阶段
- 时长：3 小时
- 难度：偏难
- 前置：1.3、2.1
- 通俗解释：理解 session、上下文和状态管理：为什么 Agent 需要记住刚才做过什么，又为什么不能无限记。
- 学完标准：能解释短会话、长会话、状态压缩和上下文污染的区别。

### 2.4 MCP 集成原理与实践
- 阶段：强化阶段
- 时长：4 小时
- 难度：偏难
- 前置：2.2
- 通俗解释：学习 MCP：把外部工具、服务、数据库安全地接给 Agent 使用，而不是让 Agent 只能空想。
- 学完标准：能连接一个简单 MCP 工具，并知道权限边界在哪里。

### 2.5 Python 实现：工作流与状态机
- 阶段：强化阶段
- 时长：3 小时
- 难度：偏难
- 前置：1.3
- 通俗解释：回到 Python 版本看工作流和状态机，理解复杂任务为什么要拆成多个明确步骤。
- 学完标准：能读懂一个状态机式 Agent 流程，并说明每个状态负责什么。

### 2.6 多 Agent 编排：主-子协作
- 阶段：强化阶段
- 时长：3 小时
- 难度：偏难
- 前置：2.5
- 通俗解释：学习主 Agent 和子 Agent 怎么协作：一个负责总控，多个专门角色负责检索、分析、检查或执行。
- 学完标准：能设计一个“主控 + 专家子任务”的协作结构。

### 2.7 RAG 概念与检索工作流
- 阶段：强化阶段
- 时长：3 小时
- 难度：偏难
- 前置：1.2、2.6
- 通俗解释：理解 RAG：不是让模型凭记忆瞎答，而是先从资料里找证据，再让模型基于证据回答。
- 学完标准：能讲清楚检索、切片、召回、重排、生成这几个环节。

### 2.8 向量数据库选型与实操
- 阶段：强化阶段
- 时长：3 小时
- 难度：偏难
- 前置：2.7
- 通俗解释：认识向量数据库和检索落地方式，知道资料为什么要转成向量，以及如何选工具。
- 学完标准：能完成一次资料入库和检索测试。

### 2.9 工具调用错误处理与降级策略
- 阶段：强化阶段
- 时长：2 小时
- 难度：偏难
- 前置：2.3、2.4
- 通俗解释：学习工具调用失败时怎么办：超时、参数错、权限拒绝、结果不可信，都要有备用方案。
- 学完标准：能给一个工具调用流程写出失败处理和降级策略。

### 2.10 证据跟踪、批准门控与风险审计
- 阶段：强化阶段
- 时长：3 小时
- 难度：偏难
- 前置：2.6、2.9
- 通俗解释：把证据链、人工批准和风险审计放进系统，避免 Agent 黑箱行动或直接干危险操作。
- 学完标准：能设计一个“先展示证据，再请求批准，最后执行”的流程。

### 2.11 短期与长期记忆
- 阶段：强化阶段
- 时长：3 小时
- 难度：中等
- 前置：2.3
- 通俗解释：理解短期记忆和长期记忆：哪些信息只在当前任务里用，哪些信息值得长期保存。
- 学完标准：能制定一套简单的记忆写入和清理规则。

### 2.12 评估与自我改进机制
- 阶段：强化阶段
- 时长：4 小时
- 难度：挑战
- 前置：2.6、2.10
- 通俗解释：学习怎么评估 Agent：答案对不对、证据够不够、行动是否安全、失败后有没有改进。
- 学完标准：能写出一组评估指标和最小测试样例。

### 3.1 框架对比：OpenCode vs Codex vs Claude Code
- 阶段：冲刺阶段
- 时长：3 小时
- 难度：中等
- 前置：2.1、2.2
- 通俗解释：比较 OpenCode、Codex、Claude Code：不是背名字，而是知道不同工具适合解决什么问题。
- 学完标准：能说清楚何时用现成工具，何时才需要自己写框架代码。

### 3.2 配置仓库环境与运行测试
- 阶段：冲刺阶段
- 时长：3 小时
- 难度：中等
- 前置：1.4、2.1
- 通俗解释：把仓库环境跑起来，安装依赖、运行测试，先确认系统能动再做改造。
- 学完标准：能本地运行项目，并知道测试失败时从哪里查。

### 3.3 创建一个专业 Agent（研究 Agent 原型）
- 阶段：冲刺阶段
- 时长：4 小时
- 难度：偏难
- 前置：3.2、2.2
- 通俗解释：开始做最终项目的雏形：一个面向研究任务的专业 Agent。
- 学完标准：能让 Agent 接收问题、拆解任务并准备检索资料。

### 3.4 创建一个可复用 Skill（证据记录 Skill）
- 阶段：冲刺阶段
- 时长：4 小时
- 难度：偏难
- 前置：3.3、2.8
- 通俗解释：做一个证据记录 Skill，把“找到的资料、引用位置、判断依据”规范地保存下来。
- 学完标准：能输出结构清晰、可回查的证据记录。

### 3.5 连接一个安全的 MCP 服务器
- 阶段：冲刺阶段
- 时长：3 小时
- 难度：偏难
- 前置：2.4、3.3
- 通俗解释：接入一个安全 MCP 服务器，让 Agent 可以调用外部能力，但行动前有边界和确认。
- 学完标准：能演示一次安全工具调用，并解释为什么它不会乱操作。

### 3.6 扩展与测试 Python 组件
- 阶段：冲刺阶段
- 时长：3 小时
- 难度：中等
- 前置：3.2
- 通俗解释：补充 Python 组件和测试，把前面学的工作流、状态、检索等能力做得更稳。
- 学完标准：能跑通关键测试，并修复至少一个小问题。

### 3.7 证据优先 Agent 工作流设计蓝图
- 阶段：冲刺阶段
- 时长：3 小时
- 难度：挑战
- 前置：3.4、3.5、2.10、2.12
- 通俗解释：画出最终 evidence-first research agent 的蓝图：输入、检索、证据、生成、审查、回退。
- 学完标准：能给出一张完整流程图和模块说明。

### 3.8 工作流实现与集成测试
- 阶段：冲刺阶段
- 时长：4 小时
- 难度：挑战
- 前置：3.7
- 通俗解释：把蓝图落地成可运行工作流，并用集成测试证明它不是纸上谈兵。
- 学完标准：能跑一个端到端演示：输入问题、检索证据、输出带引用答案。

### 3.9 故障检测与回退策略实战
- 阶段：冲刺阶段
- 时长：3 小时
- 难度：偏难
- 前置：3.8、2.9
- 通俗解释：专门练故障检测和回退：工具失败、证据不足、模型胡说时，系统怎么稳住。
- 学完标准：能展示至少两种失败场景和对应备用路径。
